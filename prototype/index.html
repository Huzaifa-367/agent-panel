Agent Panel prototype

The visual spec for the panel's webview. One chat that runs Claude (your Claude plan) and Cursor (your Cursor plan), in Cursor's own look: quiet, dense, and drawn from the editor's theme.

States

  • Agent turnTool steps, file cards with +/− and diffs, Accept and Reject, the changes bar, switching engine mid-thread, a turn still running.
  • Hand-offClaude plans, Cursor builds, Claude reviews: the plan card, hand-over notes, review findings.
  • Permissions and errorsInline permission prompts, denied steps, engine errors, a folder without git.
  • New chat and historyThe empty thread and recent threads for the workspace.
  • Pickers and mentionsEngine switch, model and mode menus, the @ file popover, tables and code blocks.

Direction

  • Cursor's chat, rebuilt with discipline. The loudest thing on screen is the work: file names and +/− counts. Everything else is muted.
  • Every colour and font comes from the editor theme through --ap-* tokens, so it fits any Cursor theme, dark or light.
  • Two families (UI font, editor font), four sizes (11, 12, 13, 14), spacing on a 4px scale.
  • Engines are a coloured dot and a word: orange for Claude, blue for Cursor. No logos.
  • No gradients, glass, emoji icons or stacked shadows. Icons are codicons.

Files

  • css/tokens.css: theme tokens. The --ap-* block goes into the extension; the --vscode-* values are preview stand-ins.
  • css/base.css, thread.css, steps.css, file-card.css, composer.css, plan.css: one file per component group.
  • css/preview.css: this page's chrome only.
  • js/menus.js, js/prototype.js: menus and interactions; the behaviour is part of the spec.
