Pickers and mentions

The engine switch, model and mode menus, the @ file popover, and how answers with tables and code render.

Replicate

  • Engine switch (.ap-seg): two options, each a coloured dot and a name. Each engine remembers its own model.
  • Model menu: grouped by engine, labelled with whose plan pays for it. Cursor's list comes from agent --list-models, cached.
  • Mode menu: Agent, Plan, Hand-off, each with one line on what it does.
  • Menus open upward from their button, stay inside the panel, close on Escape or an outside click.
  • Typing @ opens the file popover above the box: fuzzy match in bold, folder path muted, arrow keys and Enter pick, the pick becomes a chip.
  • Code blocks have a language label and a copy button; tables use quiet rules.

Try

  • Pick a file in the popover: it turns into a chip.
  • Open the model and mode menus; switch engine and open the model menu again.
  • Copy the code block.
